# 🧩 02 — Графическая среда: i3 + Openbox

**Цель:** Подготовить конфигурации для лёгкой установки i3 (tiling) и Openbox (stacking) с переключением на этапе установки/настройки.  
**Статус:** 🚧 План  
**Приоритет:** средний—высокий

## Описание
Предоставить готовые dotfiles и конфигурации для i3 и Openbox, автозагрузку Xorg, политику по оформлению, и набор приложений для рабочего окружения (terminal, rofi/dmenu, file manager, compositor).

## Компоненты
- i3wm + i3status/waybar (опционально)
- Openbox + tint2/obconf
- Xorg/xf86-video-драйверы
- Display manager (lightdm/sddm) — optional
- Набор приложений: st/kitty, thunar/pcmanfm, firefox, network-manager-applet, pulseaudio/pipewire
