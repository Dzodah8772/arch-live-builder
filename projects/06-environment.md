# 🌍 Проект: окружение разработки и сборки

**Цель:** описать стандартизированное окружение для разработки и сборки ArchFlux OS.  
**Статус:** 🚧 В разработке  
**Приоритет:** средний

## Описание
Единое окружение ускоряет онбординг и снижает количество ошибок при сборке ISO.
Проект фиксирует набор инструментов, переменные окружения, типовые сценарии
запуска сборки (локально, Docker, CI) и рекомендации по виртуализации.

## Требования к окружению
- **ОС:** Arch Linux (предпочтительно) или контейнер/Docker с `pacman`.
- **Пакеты:** `archiso`, `git`, `base-devel`, `docker` (опционально).
- **Сеть:** доступ к зеркалам `pacman`.

## Артефакты и структура
- **`packages.x86_64`** — список пакетов для ISO.
- **`airootfs/`** — overlay файловой системы live-окружения.
- **`scripts/build.sh`** — основной сценарий сборки.
- **`projects/`** — дорожная карта и задачи.

## Этапы реализации
- [ ] Определить минимальный набор зависимостей и их версии.
- [ ] Подготовить инструкцию по локальной сборке и типичным ошибкам.
- [ ] Описать Docker-процесс сборки и обязательные переменные окружения.
- [ ] Добавить шаблон CI (GitHub Actions) для nightly-сборок.

## Критерии готовности
- Новые участники могут собрать ISO по инструкции за 1 запуск.
- Документация покрывает локальную, контейнерную и CI-сборку.
- Есть краткий FAQ по частым ошибкам.

## Риски и зависимости
- Недоступность зеркал `pacman`.
- Различия в версиях `archiso`.
- Ограничения сети/прокси в CI.
