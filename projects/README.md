# 🗺️ ArchFlux OS — Project Roadmap

Добро пожаловать в секцию **Projects** — здесь описаны этапы развития ArchFlux OS, ключевые задачи и будущие направления.

---

## 📍 Текущие направления

1. **Базовая система** — минимальный Arch Linux с сетевыми инструментами и init.
2. **Графическая среда** — интеграция i3 и Openbox с автозагрузкой Xorg.
3. **Сборка ISO** — автоматизированный билд через `archiso` и Docker.
4. **Виртуализация** — готовность для VirtualBox, QEMU, VMware.
5. **Автоматизация** — PowerShell и Bash-скрипты для CI/CD.
6. **Будущее** — создание собственного установщика и GUI-оболочки.
