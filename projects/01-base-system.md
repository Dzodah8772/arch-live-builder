# 🧩 01 — Базовая система

**Цель:** Создать минимальный, стабильный базовый образ ArchFlux OS для дальнейшей кастомизации и сборки ISO.  
**Статус:** 🚧 План / Начало  
**Приори��ет:** высокий

## Описание
Минимальная система на базе Arch Linux с комфортным минимальным набором пакетов для работы в консоли, сетевых инструментов и системы инициализации (systemd). Образ должен быть небольшим, модульным и легко расширяемым.

## Основные требования
- Минимальный набор пакетов: base, linux (или кастомное ядро), networkmanager или systemd-networkd, openssh, sudo, bash, coreutils.
- Конфигурация locale и timezone.
- Стандартные пользователи и безопасные ssh-ключи.
- Репозитории и mirrorlist оптимизированные для CI.
