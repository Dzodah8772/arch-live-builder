# 🧩 03 — Сборка ISO / archiso / Docker

**Цель:** Автоматизировать сборку ISO образа ArchFlux OS через `archiso` и предоставить возможность билдить в Docker/CI.  
**Статус:** 🚧 План  
**Приоритет:** высокий

## Описание
Настроить reproducible-пайплайн, который берёт конфиги из репозитория, собирает iso и выдаёт артефакт (ISO). Поддержка сборки локально и в контейнере.

## Компоненты
- archiso конфигурация (custom releng)
- Dockerfile для сборки iso (для CI)
- GitHub Actions / GitLab CI пример workflow
- Подпись артефактов (GPG)

## Этапы реализации
- [ ] Подготовить базовый archiso профиль
- [ ] Dockerfile для сборки в чистом окружении
- [ ] CI workflow: build -> test (boot в QEMU) -> upload artifacts
- [ ] Документация: как локально собрать ISO

## Проверки
- [ ] ISO загружается в QEMU
- [ ] Установщик/скрипт установки работает корректно
