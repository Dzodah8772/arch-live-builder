# 🧩 03 — Сборка ISO / archiso / Docker

**Цель:** Автоматизировать сборку ISO образа ArchFlux OS через `archiso` и предоставить возможность билдить в Docker/CI.  
**Статус:** 🚧 В работе (MVP готов)  
**Приоритет:** высокий

## Описание
Настроен базовый reproducible-пайплайн, который берёт конфиги из репозитория, собирает ISO и отдаёт артефакт в `out/`.
Поддерживаются локальная сборка, Docker и CI через GitHub Actions.

## Компоненты
- archiso конфигурация (на базе `releng`)
- Dockerfile для сборки ISO
- GitHub Actions workflow для сборки и публикации артефактов
- Подготовка к будущему добавлению подписи артефактов (GPG)
